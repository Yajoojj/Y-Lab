# Y-Lab Fase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Hub local (Node) que coleta o estado dos agentes e o transmite por SSE para uma torre 3D neon-noir com HUD.

**Architecture:** npm workspaces `hub` e `web`. Coletores e `POST /api/events` geram `AgentPatch`; a `Store` aplica patches, persiste e emite `Delta`; o server expõe snapshot + SSE. O front aplica snapshot/deltas num modelo local que alimenta a cena Three.js e o HUD DOM.

**Tech Stack:** Node 20+, TypeScript 5, `tsx` (dev), `zod`, `vitest`; Vite 5, `three`, `postprocessing`; Playwright (fumaça); `concurrently`.

**Spec:** `docs/superpowers/specs/2026-11-08-ylab-fase1-design.md`

## Global Constraints

- Hub escuta só em `127.0.0.1`, porta padrão `7077`; front Vite em `127.0.0.1:5173`.
- Nenhuma requisição para fora de `127.0.0.1`, exceto Google Fonts ("Rajdhani", "JetBrains Mono").
- Coletores são somente leitura; nunca escrevem em `~/.claude` nem na pasta do K9.
- `step` ≤ 80 caracteres; `history` ≤ 10 itens; `activity` ≤ 200 itens; "Concluídos" ≤ 20 itens.
- Ativo = escrita há < 150 s; `done` após 30 min sem escrita; `done` some do andar 30 min depois.
- Coletores rodam a cada 3 s; sessões consideradas: modificadas nas últimas 6 h; ler só os últimos 250 KB do JSONL.
- Corpo de `POST` ≤ 64 KB; cor `^#[0-9A-Fa-f]{6}$`.
- Visual original: nada de logo, fonte, personagem ou asset de Cyberpunk 2077. Sem React.
- Paleta neon (usar estes valores): amarelo `#FCEE0A`, ciano `#00F0FF`, magenta `#FF2A6D`, violeta `#9D4EDD`, verde `#39FF88`, laranja `#FF8A00`, fundo `#05060B`.
- Mensagens de commit em português, no imperativo.

## Review Focus

1. JSONL com última linha parcial (sessão escrevendo agora) → linha ignorada, agente aparece normalmente. (Task 4)
2. Nome de bot com aspas, acentos ou emoji via `POST` → aceito e exibido sem quebrar HUD (texto via `textContent`, nunca `innerHTML`). (Tasks 2, 7)
3. Hub reiniciado com `data/state.json` truncado → sobe vazio e renomeia para `state.corrupt-<ts>.json`. (Task 3)
4. Requisição com `Host: evil.com:7077` (DNS rebinding) → 403. (Task 6)
5. Pasta do K9 inexistente → `/api/health` mostra erro do coletor `k9Lanes`, demais funcionam. (Tasks 5, 6)
